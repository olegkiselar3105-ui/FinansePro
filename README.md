# FinansePro

Учёт доходов и расходов в Telegram: Mini App + бот.

## Как идут данные

1. Пользователь пишет или говорит боту → Telegram отправляет сообщение на воркер (`/webhook`).
2. Голос воркер расшифровывает через Groq, текст кладёт в очередь (D1, запасной вариант — KV).
3. Открытый Mini App забирает очередь (`/api/pending`), сам разбирает фразу и сохраняет запись в облако Telegram (CloudStorage).
4. Приложение подтверждает приём (`/api/ack`) → бот меняет своё сообщение на «✅ Записано».

## Статистика

Обезличенные счётчики в D1 (только при заданном `STATS_SALT`): вместо Telegram id — HMAC-SHA256 с солью.
- `act (day, h, bot, app)` — кто был активен в день: написал боту / открыл приложение (`/api/pending`). Запись — только при первом событии дня, ≤2 на человека в день.
- `usr (h, first)` — день первого появления (новые, возврат).
- `cnt.n`, `cnt.v` — сообщения и голосовые за день (та же запись, что и дневной лимит).
- `agg (day, users, bot, app, new, msgs, voice)` — итоги дня, хранятся всегда. Считает расписание 00:10 UTC (`scheduled`), там же уборка: `act` и неактивные `usr` старше 90 дней, `cnt` старше 2 дней.
- `/stats` — сегодня, 7 и 30 дней, новые, возврат 7д/30д, сообщения и голос; кнопка «🔄 Обновить» переписывает это же сообщение. Отвечает только `OWNER_ID`. Сутки — UTC.
- Недельная сводка владельцу — по понедельникам 06:05 UTC (cron `5 6 * * 1`), с кнопкой «📊 Подробно». Чтобы кнопки работали, бот при `/stats` сам добавляет `callback_query` в подписку webhook, если её нет.

Вход: Mini App отправляет воркеру `initData` Telegram, воркер проверяет подпись токеном бота. Подпись действует 7 дней (`MAX_AGE`); старше — ответ 401, приложение останавливает опросы и просит перезапуск.

Команды бота: /start, /help, /privacy, /queue, /id, /stats (только владельцу). Лимит — `DAILY_LIMIT` сообщений в сутки (по умолчанию 30); ответ о лимите, команды и нетекстовые сообщения лимит не тратят.

## Секреты

Хранятся только в Cloudflare (Settings → Variables and Secrets): `BOT_TOKEN`, `GROQ_KEY`, `WEBHOOK_SECRET`, `STATS_SALT` (соль статистики; не менять).
Переменные: `ALLOWED_IDS` (пусто = бот открыт для всех), `DAILY_LIMIT`, `APP_URL`, `OWNER_ID` (Telegram id владельца для /stats; узнать — /id).
В репозиторий секреты не попадают никогда.

## Обновление

GitHub недоступен — всё выкладывается через API Cloudflare (ключ — сетевой секрет облачной среды):
- Сайт: `tools/pagesworker.py` собирает файлы (`index.html`, `sw.js`, `manifest.webmanifest`, `mail.html`, `privacy.html`, `_headers`, `icons/`) в один `_worker.js` → выкладка в проект Pages `finansepro`.
- Бот: `tools/deployworker.sh` — заливает `worker/worker.js` с привязками и расписанием (cron) из `wrangler.toml`; переменные и секреты остаются из панели. Перед выкладкой сохраняет прежний код для отката.
- Код: `tools/codebackup.sh save` — копия всего репозитория в закрытое хранилище Cloudflare KV.
- Секреты и переменные (`ALLOWED_IDS`, `DAILY_LIMIT`, `APP_URL`) задаются в панели, выкладка их не трогает.
