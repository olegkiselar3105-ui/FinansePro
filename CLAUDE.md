# FinansePro — инструкции для Claude

Учёт доходов и расходов в Telegram: Mini App + бот («кофе 300» → запись).
Подробности по темам (история решений, долги/цели, валюты, фокус и клавиатура iOS, прокрутка) — `docs/claude-details.md`: читать нужный раздел, когда работа касается темы. Журнал решений — `DECISIONS.md`.

## Файлы

- `index.html` (~830 КБ) — всё приложение. Читать только поиском (grep по имени функции/строке), не целиком.
- `sw.js`, `manifest.webmanifest`, `icons/`, `mail.html` (мост для письма; почта зашита и тут, и в `SUPPORT.email`), `_headers` (CSP, действует на Cloudflare).
- `worker/` — бот (Cloudflare Workers): webhook, голос → Groq Whisper, очередь фраз, `/api/pending`, `/api/ack`, обезличенная статистика. Данных пользователей не хранит; разбор фраз и все данные — в `index.html` (CloudStorage Telegram + localStorage).
- `tools/pagesworker.py` — сборка сайта для выкладки; `tools/codebackup.sh` — копии кода; `tools/diffpage.py` — страница изменений; `tools/stattest.mjs` — проверка статистики бота; `tools/rctest.mjs` — квитанции-карточки. `tools/synctest.mjs` — проверка синхронизации на двух «устройствах». `tools/i18n.mjs` + `i18n/dict.json` — переводы интерфейса. `tools/parsetest.mjs` + `tools/parsetest.json` — разбор фраз на трёх языках. `tools/plxsync.py` — копирует правила фраз из приложения в бота. `tools/codeaudit.py` — поиск мусора (функции без вызовов, стили для несуществующих классов/id).

## Правила работы

- Русский, прямо, без похвалы. Не соглашаться автоматически: слабую идею — сказать прямо и предложить лучше.
- **Ответы короткие**, как конспект: шаги с номерами, **жирным** главное, 👤/🤖 — кто что делает, «Что дальше» в конце. Без разборов и без базовых инструкций («закройте и откройте приложение, проверьте версию») — только если спросят. Во время работы — 1 фраза, что делаю.
- **Порядок (с 2026-11-09, слово пользователя):** развёрнутый план заранее не писать — сделать всё, проверить, закоммитить и **сразу выложить, не спрашивая**; затем коротко: **что сделано**, **риски**, **что можно изменить/добавить**, 1–3 рекомендации. Не выкладывать — только если пользователь сам скажет (например, пока даёт серию правок). Исключение — правки с риском для данных пользователей (миграции, облако, удаление): там короткий план и подтверждение до работы.
- **Проверки по размеру правки:** простая — 1–2 нужных теста (или скриншот); полный прогон и замеры — только для серьёзных. В выводе тестов смотреть итог (OK/FAIL, ошибки), не весь лог.
- После правок: `IB_VER` +1 (формат `v`+число, при каждой правке `index.html`; на экране и в письме — `APP_VER` = «1.<число>», считается из `IB_VER` сам, с v224), коммит, `codebackup.sh save`, файлом в чат — `index.html`. Важное решение → строка в `DECISIONS.md` (дата — решение — причина).

## Окно «Что нового»

`const WN=[...]` — **только один, последний выпуск**: новый заменяет старый, `id` новый (по нему показывается один раз, `cfg.wnSeen`). Окно ждёт человека, пока он его не закроет, — сколько бы версий ни вышло: смена `IB_VER` его не сбрасывает, сбрасывает только новый `id`. Пункты `['эмодзи','Заголовок','1–2 строки простым языком']`; новый выпуск — когда скажет пользователь. Эмодзи с текстом внутри (📅 → «July») не брать. Анимация: `.wnx`, `--i`, `--n` (v205).

## Важное в index.html

- `IB_VER`, `APP_VER` — 5–6-я строка; `IB_VER` держать в первых ~4 КБ (проверка версии читает только начало).
- Свайпы в «Операциях» (v280): `swZone` — жест, начатый в правой четверти строки или заголовка дня, — удаление (`onSwDown` на pointer, строки `touch-action:pan-y`), левее — листание месяца (touch-события `bodyEl`, туда `swZone` не пускает). Не смешивать: оба обработчика проверяют зону.
- Удаление строки (v283): `commitSw(w,vel)` — строка уезжает со скоростью пальца, схлопывание `fxCollapse(…,{ios:1})` — кривая `SPRING`, без `scale`. Отмена — зеркально: `fxBack` (место раскрывается пружиной, строка въезжает слева, подложка втягивается). v284: плашка `#toast` — стекло и место нижней панели (капсула по центру), панель на это время уходит (`:has(#toast.on:not(.kb))`). Меню «⋯» (`#selmore`, `touch-action:none`): если iOS оборвёт pointer-поток, палец ведут touch-события (`shTM`, `tEnd`).
- Суммы — только `fmtN`/`fmt`. Список месяца строится целиком; дни с `content-visibility:auto` (класс `cv`). Смена месяца — `swapAnim` на `el.animate` (не `pxAnim`).
- Сворачивание блока в «Аналитике»/«Планах» (v230): CSS-анимации от прокрутки (`animation-timeline: scroll()`), ключевые кадры в `#colkf` пишет `colBuild` при замере мест шапки (`meas`); запасной путь — те же анимации на паузе + `--coly`. Блок сплошной, без тени, строка разделов под ним (z-index) — подложек и подрезки строки нет (v231). Доводка — `scrollTo smooth` после `scrollend`. Не возвращать JS-расчёт на каждом кадре (на iPhone отстаёт и дёргается).
- Нижняя панель (v248): сжатие — только transform/opacity (половинки фона `.tbg`, `fix()` закрепляет состояние в стилях, снятие в два кадра — v249); clip-path и пересоздание анимаций без закрепления не возвращать — в Safari мерцает. `tbSet(false)` на развёрнутой стоящей панели ничего не делает (v250): иначе `fix()` снимает у подсветки `.ind` переход и она перескакивает при смене вкладки. v251: значок 30 px + подпись `.tbt` 10,5 px в прежней кнопке 68×56 (в капсуле `.tbs` подпись гаснет, значок по центру); анимация значка при выборе — `tbPop` (`TB_POP`; v252: длительности ×1,5, у «Планов» стрела `.ar` летит в центр мишени и остаётся; Web Animations на частях svg, без чтения размеров); пока палец ведёт по панели (`window.__tbDrag`), `moveInd` ничего не делает.
- Знакомство (v257): `AppOnb` (`#onb`, шаги `STEPS`) — при первом запуске вместо тура `AppTour` (тур — только «Настройки → Обучение»); отметка `cfg.onb=1`; ждёт `CL.ready` в Telegram, заставку и PIN-экран; пока решается — `window.__onbWait`, открыто — `window.__onbOn` (учитывают `isModalOpen`, «Что нового», советы, меню). Валюту при наличии записей не менять.
