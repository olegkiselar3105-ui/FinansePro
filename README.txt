КАК ВЫЛОЖИТЬ (бесплатно, нужен HTTPS)

Cloudflare Pages / Netlify: создайте проект, перетащите ВСЮ эту папку (не zip) — готово.
GitHub Pages: загрузите содержимое в репозиторий, Settings → Pages → Deploy from branch.

ПЕРЕД ПЕРЕНОСОМ ДАННЫХ
Данные хранятся в браузере по адресу сайта. На новом адресе приложение будет пустым.
Старую версию: Настройки → сохранить копию. Новую: восстановить из копии.

ОБНОВЛЕНИЯ
Изменили index.html — поменяйте VERSION в sw.js (finance-v1 → finance-v2), иначе
у пользователей останется старая версия из кэша.

УСТАНОВКА
Android/Chrome: меню → «Установить приложение». iPhone/Safari: Поделиться → «На экран Домой».
